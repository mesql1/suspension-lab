# Modelo 3D do veículo

`mustang.glb` é a versão otimizada para navegador do arquivo
`25-mustang-13.04.2021-obj.zip`, fornecido pelo responsável pelo projeto.

O OBJ original tinha aproximadamente 728 mil faces e não incluía o arquivo
MTL nem texturas. Para uso no Suspension Lab, a carroceria foi normalizada,
reduzida para cerca de 25 mil triângulos e recebeu materiais compatíveis com a
identidade visual da aplicação. As rodas do arquivo foram removidas: a cena usa
rodas procedurais separadas para que os eixos dianteiro e traseiro possam
acompanhar independentemente a entrada da pista.
